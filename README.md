# ACraft

ACraft is an original lightweight block-building PWA game.

## Controls
- Desktop: A/D or arrow keys to move; W/Space to jump.
- Tap/click nearby blocks to mine.
- Select a hotbar block and tap/click empty nearby space to place it.
- Keys 1–7 select hotbar slots.
- Mobile includes on-screen controls.
- World and inventory autosave in localStorage.

## PWA
The app includes a web manifest and service worker for standalone/offline use when served over HTTPS.
